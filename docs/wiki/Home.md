# 千里腿

千里腿是 `meridian_peddler` 的一书三卷腿法目录：上卷「赶路」含弹腿、正蹬、扫堂和训练式蹲马步，中卷「拦路」含鞭腿、连环、尥蹶，下卷「千里」含飞踹、下劈、不留行。

本仓只提供功法目录、七种伤害类型和标签。功法库负责解析书卷、承接、做功、曲线与着地规则；Damage 负责部位与肌肉系数；Human 负责腿击宿主、靴子和世界事实；Players-Animation 负责 `meridian_peddler:peddler_*` 表现。
